# Stack tecnológica

## Base

- TypeScript como linguagem principal.
- React para a interface principal do site.
- SQLite como banco de dados inicial.
- Estrutura voltada para páginas responsivas e modernas.

## Motivos

- TypeScript oferece mais segurança e manutenção no código.
- React facilita a criação de interfaces dinâmicas e reutilizáveis.
- SQLite atende bem ao estágio inicial do projeto.
- O conjunto permite desenvolvimento rápido e compatibilidade com navegadores modernos.

## Requisitos do projeto

- Layout responsivo para dispositivos móveis.
- Login administrativo para cadastro e edição de notícias.
- Catálogo de cursos técnicos com descrições e matrizes curriculares.
- Conteúdo institucional claro e visualmente atrativo.
